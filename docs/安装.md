# 安装与常见问题

[返回首页](../README.md) · [文档导航](README.md)

## 准备条件

- Windows 上的 DSH Desktop，且 `git`、`dsh` 命令可用。
- 本机已经安装 Wallpaper Engine；需要的工坊项目已下载，或存在 WE 本地项目。
- 如果想在 DSH 中浏览和显示壁纸，还需对应的消费方界面；当前库桥没有自己的图库页面。

项目没有普通运行时 npm 依赖；场景静态合成所需的 `sharp` 从宿主环境寻找。需要原生实时场景时，再看[桥](桥.md)。

## 普通安装

等任务结束，完全退出 DSH Desktop。以下目录是示例，可以改成自己的绝对路径：

```powershell
git clone https://github.com/Raylen-berry/dsh-WE-library.git D:\dsh-plugins\dsh-WE-library
dsh plugin --profile desktop add link:D:/dsh-plugins/dsh-WE-library
```

重新打开 DSH Desktop，在「设置 → 插件」检查启用状态。启动日志应出现 `[dsh-we-library] host up`，并提示 `/dwl/*` 路由和静态图目录。

**仓库目录名可以带大写，包名必须是小写 `dsh-we-library`。** 本仓库的挂载示例使用 `desktop` profile，手动配置依赖和 bundle 时也使用小写包名。

普通安装只挂载库接口，不会自动安装原生桥或迁入图库界面。

## 更新与停用

在插件目录先检查有没有自己的修改；处理好后执行 `git pull --ff-only`。随后完全退出并重新打开 DSH Desktop，等待正在执行的任务结束再重启。

可在「设置 → 插件」停用库桥。若曾安装原生桥，还需要按[桥的回退说明](桥.md)处理桌面入口；仅停用库接口不等于移除 Electron 的原生桥加载入口。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 安装后没有选壁纸页面 | 独立图库尚未迁入，本插件目前提供接口，界面仍由底图插件负责 |
| 日志出现 `failed to import` | 检查依赖和 patch 中是否使用小写包名，链接目录是否存在 |
| 返回 `weFound: false` | 先确认本机 WE 可运行，再检查 Steam 安装信息和项目路径 |
| WE 找到了，但某些项目没有列出 | 需存在有效 `project.json`；当前扫描发现的 WE 所在 Steam 库，不聚合所有库根 |
| 新下载的项目暂未出现 | 库清单默认缓存约 60 秒，接入方可用 `?force=1` 强制重新扫描 |
| 场景静态图失败 | 检查 `scene.pkg`、宿主 `sharp` 和目录写入条件；部分场景无法静态合成 |
| WE 界面打开了，却没有切到指定壁纸 | WE 原先没运行时只启动界面，等待运行就绪后再发送一次 |
| 实时功能不可用 | 普通库接口不等于实时采集能力，需 Windows 原生桥和消费方接入 |

状态及文件入口见[使用](使用.md)和[接口](接口.md)。
