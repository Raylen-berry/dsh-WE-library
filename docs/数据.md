## 原文件与派生数据

| 数据 | 位置 | 用途 |
| --- | --- | --- |
| WE 订阅与本地项目 | Steam 工坊目录、WE 的 `projects` 目录 | 读取现有项目与媒体；克隆插件不会下载这些壁纸 |
| 场景静态 WebP | `DSH_HOME/dsh-we-library/we-stills/` | 静态合成缓存，可在条件满足时重新生成 |
| 原生场景属性和预设 | Electron 的 `userData/harness/dsh-we-library/we-scene-properties.json` | 按场景保存属性和最多 12 个命名预设 |
| 原生安装备份 | 执行安装器时指定的 `--backup` 目录 | 保存被改写的 DSH main、preload 文件和摘要 |

**库接口的数据目录与 Electron 原生属性目录不是同一个配置来源。** 不能仅备份静态图目录，就认为已备份原生属性或安装入口。

## 路径设置

| 环境变量 | 控制范围 |
| --- | --- |
| `DSH_HOME` | 宿主数据根；Windows 未设置时，库桥默认使用 `%USERPROFILE%\.dsh` |
| `DSH_WE_LIBRARY_DIR` | 覆盖库接口的数据目录，静态图存入其 `we-stills` 子目录 |
| `DSH_WE_LIBRARY_SHARP` | 显式指定可加载的 `sharp` 模块路径或模块 URL |

这些变量控制宿主侧的派生图与模块查找，不会改变原生桥使用 Electron `app.getPath('userData')` 确定的场景属性位置。

`sharp` 默认依次尝试显式指定位置、普通模块导入、宿主 profile 共享目录和应用内副本。静态合成失败时先看返回原因，而不是修改 WE 原项目。

## 换电脑时

先在新机器准备 WE 和所需项目，再安装库桥。静态图可复制保留，或在模块和项目齐全时重新生成；原生属性需要单独备份对应 JSON。

工坊 ID 来自项目目录名，本地 ID 来自项目相对路径的摘要；更换本地项目的分组或目录名可能改变 ID，旧属性预设不会自动匹配到新 ID。

原生桥的安装入口和绝对模块路径属于每台机器的应用目录，应重新预览安装；不要把旧机器修改后的 DSH 文件直接覆盖到新版本应用。
