# Wallpaper Engine 库桥

把本机 **Wallpaper Engine** 的订阅壁纸与本地项目接入 DSH，为背景插件提供库清单、媒体文件和场景静态图。

> **当前处于独立迁移阶段。** 本仓库提供后台接口和原生桥代码，尚未包含独立图库界面。安装后不会自动出现选壁纸页面或更换 DSH 背景；目前的图库和属性界面仍在底图插件中。

仓库名 `dsh-WE-library` · 安装包名 **`dsh-we-library`** · MIT 许可证

[安装](docs/安装.md) · [功能与用法](docs/使用.md) · [原生桥接入](docs/桥.md) · [文档导航](docs/README.md)

## 可以做什么

| 能力 | 具体用途 | 当前条件 |
| --- | --- | --- |
| **发现本地壁纸库** | 读取 Steam 工坊订阅与 WE 本地项目，返回标题、类型、标签和预览信息 | 本机已安装 WE，项目已下载 |
| **提供媒体文件** | 让接入方读取项目里的预览图、视频、网页等文件 | 通过库里的项目 ID 访问 |
| **生成场景静态图** | 将可解析的 `scene.pkg` 合成为 WebP，供背景插件显示 | 需要可用的 `sharp`；属于静态近似 |
| **发送到 WE** | 使用 WE 官方命令打开指定项目 | WE 需先运行；未运行时先打开 WE 界面 |
| **接入实时场景** | 使用 WE 自己的引擎运行场景，由桌面原生桥连接消费方 | Windows、原生桥安装及客户端接入 |

## 它和底图插件怎么配合

| 插件 | 负责什么 |
| --- | --- |
| **本插件：库桥** | 找到壁纸、提供文件和场景画面相关能力 |
| **dsh-bg-atelier-plus：底图插件** | 提供背景界面，把画面绘制到 DSH 中 |

当前两个仓库还在拆分中：库桥使用 `/dwl/*` 接口，底图插件保留自己的 `/bga/we/*` 和现有界面。安装库桥不会自动把底图界面切换到新接口。原生实时桥的共享安装入口另见[接入指南](docs/桥.md)。

## 第一次接触

1. 先读[功能与用法](docs/使用.md)，确认自己需要库接口，还是现有底图界面的背景功能。
2. 按[安装说明](docs/安装.md)安装库桥，等正在执行的任务结束后，完全退出并重新打开 DSH Desktop。
3. 用启动日志确认 `dsh-we-library` 已加载；需要接入时，再读取库清单和状态接口。
4. 只有需要开发或迁移实时场景接入时，再阅读[原生桥](docs/桥.md)与[画面接口](docs/接口.md)。
