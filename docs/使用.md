# 功能与用法

[返回首页](../README.md) · [文档导航](README.md)

本插件当前是提供能力的库桥。它能读取本机已有项目，但没有独立的设置图库或一键换背景界面；现有底图界面也尚未自动改用本仓库的新接口。

## 库里读哪些内容

发现逻辑先读取 Steam 注册表信息，再读取 `libraryfolders.vdf`，最后尝试候选安装目录。找到 WE 后，扫描对应 Steam 库的工坊目录与 WE 的 `projects` 目录。

| 来源 | 扫描范围 |
| --- | --- |
| Steam 创意工坊 | 已下载的 WE 订阅项目，应用 ID `431960` |
| WE 本地项目 | `projects/<项目>` 或 `projects/<组>/<项目>` 中有效的 `project.json` |

清单按标题排序，提供类型、标签、预览图和配色等信息。当前发现第一个有效 WE 安装后，就使用其对应库根；读取多库配置不代表会合并扫描所有 Steam 库。

## 不同类型怎么使用

| 类型 | 库桥提供什么 | 显示由谁完成 |
| --- | --- | --- |
| 视频 `video` | 原项目的视频文件与预览 | 消费方的视频背景层 |
| 网页 `web` | 原项目的 HTML、脚本、样式及媒体 | 消费方的网页承载界面 |
| 场景 `scene` | 预览信息、可生成的静态图、WE 启动及原生接入能力 | 静态图片层，或接入原生桥的客户端 |

提供项目文件不等于把场景转换成网页，也不保证任意网页壁纸已经适配 DSH。清单里其他或未知类型可被列出，但不能据此推断已支持完整播放。

## 场景静态图

静态合成读取可解析的 `scene.pkg`，输出 WebP。接入方先发生成请求，再查看状态或读取生成后的 `still` URL。

这是**静态近似**，不会运行 SceneScript、粒子、动态效果或 WE 的完整引擎。需要完整效果时使用 WE 本身；图生成失败时，消费方可以保留项目预览并显示原因。

合成依赖宿主可用的 `sharp`；任务有队列、超时与资源上限，失败后有短暂重试冷却。生成图的位置见[数据](数据.md)。

## 发送到 Wallpaper Engine

`open-in-we` 接口支持 `scene / web / video` 项目。WE 已运行时，调用官方命令发送选定项目；WE 没运行时，只打开其界面，并返回「运行就绪后请再点一次」。

这个动作是在 WE 中打开项目，不会自动把它变成 DSH 背景。

## 实时场景

实时模式由 WE 的引擎运行场景，原生桥控制专用窗口；客户端还需要采集和呈现画面。普通浏览器没有 Electron preload 提供的能力，无法走这条原生接入流程。

桥代码已迁入本仓库，图库 UI、属性 UI 和消费方切换仍在迁移范围内。接入条件见[桥](桥.md)，开发契约见[接口](接口.md)。

## 安装后怎样确认

先看宿主日志确认库桥加载。懂接口的接入者可以通过同一个 DSH 本机服务的 `/dwl/status` 查看发现和进程状态，通过 `/dwl/library.json` 读取清单；无需猜一个固定端口。

状态中的 WE 进程或端口可用，不能单独证明实时桥已装好或画面已成功采集。
